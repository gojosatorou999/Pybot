# Pybot

A extremely minimal chatbot built with Python's standard library. It does not use external web frameworks, CSS, or JavaScript.

## Features
- **100% Pure Python**: Uses only standard built-in libraries (`http.server` & `socketserver`).
- **No CSS / No JavaScript**: Built purely with simple HTML standard elements.
- **18 Predefined Responses**: Hardcoded keyword/phrase-based interactions.
- **Last Interaction Display**: Keeps track of the absolute last user message and the chatbot response.

## Quick Start
1. Clone this repository:
   ```bash
   git clone https://github.com/gojosatorou999/Pybot.git
   cd Pybot
   ```
2. Start the chatbot server:
   ```bash
   python chatbot.py
   ```
3. Open your browser and navigate to:
   ```
   http://localhost:8080
   ```
